# 📊 Анализ данных сервиса доставки еды

Этот проект содержит комплексный анализ данных для сервиса доставки еды. Включает в себя финансовые метрики, когортный анализ удержания клиентов, RFM-сегментацию и анализ заказов с построением интерактивных графиков.

## 🛠 Технологии

* **Python 3.12**
* **Jupyter Notebook**
* **Pandas** (обработка данных)
* **NumPy** (математические вычисления)
* **Matplotlib** (базовые графики)
* **Seaborn** (тепловые карты и красивая визуализация)
* **Statsmodels** (проверка статистических гипотез)
* **IPywidgets** (интерактивный дашборд)
